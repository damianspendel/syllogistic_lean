How it is verified

Venn diagrams decide validity

For three terms a model can only tell us which of the eight regions are inhabited, so there are 2⁸ = 256 Venn models. The library proves that validity over every model on every type equals validity over these 256. The kernel then evaluates all 256 × 256 cases.

Aristotle's proof system matches

Barbara and Celarent as axioms, three conversion rules and reductio. The exercises prove this system sound and derive all 24 moods, so it proves exactly the valid syllogisms (Corcoran 1972, Smiley 1973).

theorem valid_iff_vennValid (ei : Bool) (σ : Syllogism) :
    Valid ei σ ↔ vennValid ei σ = true

theorem trad_classification :
    ∀ σ ∈ allSyllogisms, TradValid σ ↔ σ ∈ traditionalMoods      -- 24

theorem modern_classification :
    ∀ σ ∈ allSyllogisms, ModernValid σ ↔ σ ∈ modernMoods         -- 15

theorem provable_iff_valid :                                     -- Exercise 5
    ∀ σ ∈ allSyllogisms, Provable σ ↔ TradValid σ
